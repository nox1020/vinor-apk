# دارایی فروشگاه وینور

آماده‌سازی انتشار کافه‌بازار و گوگل‌پلی. از این پوشه چیزی به فروشگاه فرستاده نمی‌شود.

| فایل | کاربرد |
|---|---|
| `listing-fa.md` | عنوان و توضیح فارسی، هر دو فروشگاه |
| `listing-en.md` | عنوان و توضیح انگلیسی پلی |
| `release-notes.md` | یادداشت نسخهٔ ۱.۰.۱۴۹۴ و دستور ساخت |
| `checklist.md` | گام‌های کنسول پلی و پنل بازار |
| `privacy.md` | نشانی سیاست منتشرشده؛ پیش‌نویس تازه نیست |
| `icon-512.png` | آیکون ۳۲بیتی مات |
| `feature-graphic-1024x500.png` | گرافیک ویژگی بدون کانال آلفا |
| `screenshots/01-home.png` | نمای واقعی خانه، ۷۲۰×۱۲۸۰. جستجو، جزئیات، پروفایل و برگه‌های بایگانی در این نوبت گرفته نشد: شبیه‌ساز روی دیالوگ گیر کرد و بایگانی بدون ورود همکار باز نمی‌شود. |

بازسازی بعد از قابلیت آرشیو در `release-notes.md` است. طعم `play` بستهٔ AAB می‌سازد، طعم `bazaar` بستهٔ APK، و طعم `sideload` همان APK سایت است.
